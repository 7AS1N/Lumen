Lumen

A tiny, beautiful, classless CSS framework. Write semantic HTML and it just looks great. No classes, no JavaScript, no build step.

Get started View on GitHub

Install

Add one line to your <head>. That's it.

CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/7AS1N/Lumen/lumen.css">

Download

Grab lumen.css from the repo, drop it in your project and link it:

<link rel="stylesheet" href="lumen.css">

Starter template

<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>My site</title>
  <link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/7AS1N/Lumen/lumen.css">
</head>
<body>
  <header><h1>Hello</h1></header>
  <main><p>Styled with zero classes.</p></main>
</body>
</html>

Layout

A section that contains articles becomes a responsive auto-fit grid. An aside beside your content becomes a sticky sidebar. Resize this window to watch it flow.

Classless

Elements are styled by what they are.

Lightweight

One small stylesheet and nothing else.

Dark mode

Follows your system theme automatically.

</section>

Forms

Wrap controls in a label and a form. Text inputs, textarea, select, checkbox and radio are all styled.

Preferences
Plan

View code 
<form>
  <label>Email
    <input type="email" placeholder="ada@example.com">
  </label>

  <label>Topic
    <select>
      <option>General question</option>
      <option>Bug report</option>
    </select>
  </label>

  <label>Message
    <textarea></textarea>
  </label>

  <fieldset>
    <legend>Preferences</legend>
    <label><input type="checkbox"> Email me updates</label>
    <label><input type="radio" name="plan"> Free</label>
  </fieldset>

  <p>
    <button type="submit">Send</button>
    <button type="reset">Reset</button>
  </p>
</form>

Buttons

Submit buttons are filled with a gradient. type="button" and type="reset" become outlined. Use role="button" on a link to make it look like a button.

Link button

View code 
<button>Primary</button>
<button type="button">Secondary</button>
<a role="button" href="#">Link button</a>
<button disabled>Disabled</button>
